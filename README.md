# Mag-Cup 4D

**An Open-Source 4-Pole Magnetic Separation Rack for Laboratory Research**

Mag-Cup 4D is a low-cost, 3D-printable magnetic separation rack designed for 1.5 mL and 2 mL microcentrifuge tubes.

The device uses a four-pole permanent magnet configuration with a ferromagnetic yoke to support column-free magnetic separation workflows.

## Features

- Four-pole magnetic circuit
- Designed for standard 1.5/2 mL microcentrifuge tubes
- 3D-printable PETG components
- No external power supply required
- Prototype material cost below CNY 100
- Open hardware design for reproduction and modification

## Documentation

- 3D Printing Files — STL
- Editable CAD Models — STEP and native CAD
- Bill of Materials
- Assembly Instructions
- Magnetic Circuit Design

## Validation Status

This is a research-use hardware prototype. Performance equivalence to commercial magnetic separation systems has not yet been independently established.

## Safety

Strong neodymium magnets present pinch and magnetic-field hazards. Appropriate care is required during assembly and use.
